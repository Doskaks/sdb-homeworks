### Задание 2

Проведите сканирование Metasploitable в режимах SYN, FIN, Xmas, UDP.

Запишите сеансы сканирования в Wireshark.

Ответьте на следующие вопросы:

- Чем отличаются эти режимы сканирования с точки зрения сетевого трафика?
- Как отвечает сервер?

*Приведите ответ в свободной форме.*


### Решение 2


Отличие режимов сканирования с точки зрения сетевого трафика:

SYN сканирование (-sS):
```
Клиент → Сервер: [SYN] флаг
Сервер → Клиент: [SYN-ACK] если порт открыт, [RST] если закрыт
Трафик: 2-3 пакета на порт
```

FIN сканирование (-sF):
```
Клиент → Сервер: [FIN] флаг
Сервер → Клиент: НЕТ ОТВЕТА если порт открыт, [RST] если закрыт
Трафик: 1-2 пакета на порт
```

Xmas сканирование (-sX):
```
Клиент → Сервер: [FIN+PSH+URG] (все флаги "горят")
Сервер → Клиент: НЕТ ОТВЕТА если порт открыт, [RST] если закрыт
Трафик: 1-2 пакета на порт
```

UDP сканирование (-sU):
```
Клиент → Сервер: UDP пакет (без установки соединения)
Сервер → Клиент: UDP ответ если служба отвечает, ICMP Port Unreachable если закрыт
Трафик: 1-2 пакета на порт
```

Ответы сервера Metasploitable:

На открытые TCP порты (21, 22, 23, 25):
```
SYN сканирование:  [SYN-ACK]
FIN сканирование:  нет ответа
Xmas сканирование: нет ответа 
```

На закрытые TCP порты (20, 24, 26-30):
```
SYN сканирование:  [RST]
FIN сканирование:  [RST]
Xmas сканирование: [RST]
```

На UDP порты:
```
53/UDP (DNS открыт):  UDP ответ (DNS-пакет)
69/UDP (TFTP открыт): нет ответа
123/UDP (NTP закрыт): ICMP Port Unreachable
```
